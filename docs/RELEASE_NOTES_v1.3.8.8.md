# Mio RealTime Translator v1.3.8.8

## Changes

- Added a quick-window option for `Original Text Only (Read Translation)` that sends the original text after translated TTS playback finishes.
- Improved Qwen TTS recovery from temporary audio lookup failures.
- Blocked punctuation-only OSC messages while allowing standalone `!?` and `！？` reactions in VRChat.

## Upgrade

Users on v1.3.8.6 or later can update through Mio's in-app updater. Users on v1.3.8.5 or earlier must manually install this version once.
