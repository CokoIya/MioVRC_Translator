从找素材到用上

不用在浏览器、网盘和文件夹之间来回切。

1

找

Booth 页点选分类、素体、风格标签，可以多选，不用猜日文关键词；闲鱼直接搜。买过的、素材库里已有的会标出来。

2

买

商品页、购物车、和卖家聊天都在软件里，登录保存在本机，不用切到浏览器。

3

下载

Booth 已购点一下就下载；闲鱼卖家发来的网盘分享收进来，登录百度网盘后在软件里直接下载。压缩包自动解压，下完自动入库。

4

用

选好 Unity 工程点「一键导入」：PSD 包、分卷一起解压，unitypackage 直接进工程。哪些在用、作者更新了，都会标出来。

能做什么

素材越买越多，找起来越来越难。

逛 Booth

分类、素体、风格标签多选，按人气、新上架、价格排序。卡片标出「已购」「素材库已有」，也能只看还没有的。

闲鱼

在软件里搜索、登录、和卖家聊天、下单。卖家发来的网盘分享，在聊天里选中，一键收进素材库。

已购一键下载

同步 Booth 已购，没下载的点一下就下载。压缩包自动解压，日文文件名不乱码，下完自动入库。

网盘直接下载

收进来的百度网盘分享，登录后在软件里直接下载、解压、入库，不用开网盘客户端。分享里东西多，可以只勾要的那几个；断了接着下。

一键导入工程

选好 Unity 工程点一下：PSD 包、分卷、带密码的压缩包一起解压，unitypackage 直接写进 Assets，已有的就地更新。

自动整理

认出 unitypackage、压缩包和解压后的文件夹，分好类、标出适配素体，同款合并成一张卡片；还能看出哪个素材用在哪个工程里。「工程」页一个工程一张卡片，点一下用对应版本的 Unity 打开。

开始使用

1

下载并安装

安装版默认装到 C 盘以外的磁盘，不需要管理员权限。

2

选择文件夹

选放素材的文件夹，比如 BaiduNetdiskDownload，有 Unity 工程也一起选上。

3

开始扫描

第一次会久一点。之后去「Booth」「闲鱼」页找新素材，买到的直接下载进来，再一键导入工程。

常见问题

打开时 Windows 提示「已保护你的电脑」
点「更多信息」，再点「仍要运行」。程序没有购买数字签名，所以会有这个提示。
素材库的数据存在哪里？
安装版在 %LOCALAPPDATA%\MioVRC_AssetManager，便携版在程序所在的文件夹。只保存在本机，不会上传。
买东西、聊天会跳到浏览器吗？
不会。Booth 和闲鱼的页面都在软件里打开，登录、购买、和卖家聊天、下载都在软件里完成。电脑上没有 WebView2 时，页面会开在一个单独的 Edge 或 Chrome 窗口里。
一键导入要先关掉 Unity 吗？
不用。导入是把文件直接写进工程的 Assets 文件夹，Unity 开着的话切回去就会刷新；没开就等下次打开工程。工程里已有的资源会就地更新，不会多出一份。rar、7z 和分卷压缩包用你电脑上默认的解压软件来解（7-Zip、Bandizip、WinRAR、好压等都行），普通 zip 不需要装。
下载的素材放在哪里？
没改过设置的话，放在 C 盘以外剩余空间最大的那个盘的 MioVRCdownload 文件夹，优先用你素材文件夹所在的盘；只有 C 盘时放在第一个素材文件夹里。设置 →「下载位置」可以改成别的文件夹。
网盘分享里东西很多，能只下一部分吗？
能。在素材详情的「网盘内容」里勾选要的文件或文件夹，点「下载所选」，只转存、下载勾选的部分。以后想要别的，再勾选接着下，会放进同一个文件夹。
工程卡片的「开启封面」会往工程里放什么？
一个只在 Unity 编辑器里运行的小插件（Packages/com.miovrc.projectcard）。打开工程、保存场景时，它给场景里的模型拍一张正面照，存到工程的 UserSettings/MioVRCA，旧的自动删掉。它不改场景，也不会跟模型一起上传；点「关闭封面」就会连照片一起删掉。工程里的插件管理请继续用 VCC 或 ALCOM。
百度网盘下载需要会员吗？
普通账号也能下，但百度对非超级会员限速，大文件会很慢；开通百度网盘超级会员后会快很多，软件不会绕过限速。下载时会先把分享存进你网盘的「MioVRCA」文件夹再下载到电脑，网盘里的这份不会自动删除，不需要可以自己删。
Booth、闲鱼、百度网盘的登录安全吗？
都在软件内置的页面里登录，登录只保存在你的电脑上，不读取你平时用的浏览器，也不经过任何服务器。登录会长期保留，重启、更新软件后不用重新登录。下载用的登录另外加密保存，只有你的 Windows 账户能读取；在设置里可以随时退出、更换账号。
遇到问题怎么反馈？
软件右下角有「反馈和建议」，写完直接发给作者。也可以在 GitHub 提问题。
