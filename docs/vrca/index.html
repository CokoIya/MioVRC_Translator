能做什么

素材越买越多，找起来越来越难。

自动整理

扫描素材文件夹，认出 unitypackage、压缩包和解压后的文件夹，分好类，标出适配的素体。

Booth 已购

登录一次 Booth，列出买过的所有商品，哪些还没下载一眼就能看到，点一下打开下载页。

百度网盘

记下分享链接和提取码，读出分享里有哪些文件。合集分享会按文件夹拆成一个个素材。

同款合并

同一件衣服给不同素体的包、PSD 源文件，合成一张卡片。选了素体，只显示能用的那个版本。

工程使用

分析你的 Unity 工程，标出哪个素材正在用、用在哪个工程里，没用到的也能找出来。

跟上更新

新下载的素材放进文件夹会自动收进来；网盘分享、Booth 商品页有变化时会提示。

常见问题

打开时 Windows 提示「已保护你的电脑」
点「更多信息」，再点「仍要运行」。程序没有购买数字签名，所以会有这个提示。
素材库的数据存在哪里？
安装版在 %LOCALAPPDATA%\MioVRC_AssetManager，便携版在程序所在的文件夹。只保存在本机，不会上传。
Booth 登录安全吗？
同步已购时会打开一个单独的浏览器窗口，登录信息只保存在这个窗口里，不读取你平时用的浏览器，也不经过任何服务器。
遇到问题怎么反馈？
软件右下角有「反馈和建议」，写完直接发给作者。也可以在 GitHub 提问题。
