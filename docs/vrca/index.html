✦ HOW IT WORKS

从找素材到用上

不用在浏览器、网盘和文件夹之间来回切。

下载

已购点一下就下载，网盘分享登录后直接下载，压缩包自动解压入库。

用

一键导入 Unity 工程，再用「一键改模」穿到模型上、做好菜单。

✦ ONE CLICK

一键改模

选好素体和素材，点一次「一键创建」，得到穿好衣服、做好菜单、可以上传的模型。不会 Unity 也能用。

改模篮

✦ FAQ

常见问题

打开时 Windows 提示「已保护你的电脑」
点「更多信息」，再点「仍要运行」。程序没有购买数字签名，所以会有这个提示。
素材库的数据存在哪里？
安装版在 %LOCALAPPDATA%\MioVRC_AssetManager，便携版在程序所在的文件夹。只保存在本机。
买东西、聊天会跳到浏览器吗？
不会。Booth 和闲鱼的页面都在软件里打开，登录、购买、聊天、下载都在软件里完成；闲鱼也可以改成用默认浏览器打开。
一键导入要先关掉 Unity 吗？
不用。Unity 开着的话切回去就会刷新。rar、7z 和分卷压缩包需要电脑上装有解压软件（7-Zip、Bandizip、WinRAR 等），普通 zip 不需要。
下载的素材放在哪里？
默认放在 C 盘以外剩余空间最大的磁盘的 MioVRCdownload 文件夹，可以在设置的「下载位置」里修改。
网盘分享里东西很多，能只下一部分吗？
能。在素材详情的「网盘内容」里勾选需要的文件，点「下载所选」。以后需要别的，再勾选接着下。
要花钱吗？会改坏我的工程吗？
软件免费。不用 AI 也能用；用 AI 时用的是你自己的 AI 账号，费用由服务商收取。所有改动都能撤销，软件不会替你保存场景。
百度网盘下载需要会员吗？
普通账号也能下，但百度对非超级会员限速，大文件会很慢；软件不会绕过限速。
Booth、闲鱼、百度网盘的登录安全吗？
都在软件内置的页面里登录，登录只保存在你的电脑上，不经过任何服务器。在设置里可以随时退出、更换账号。
遇到问题怎么反馈？
软件右下角有「反馈与建议」，写完直接发给作者。也可以到 QQ 交流群、Discord 里说，或者在 GitHub 提问题。
