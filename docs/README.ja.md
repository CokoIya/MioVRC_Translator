## 概要

**Mio RealTime Translator** は VRChat 向けのデスクトップ翻訳ツールです。主に次の 2 つの場面を想定しています。

- 自分の発言を翻訳して `VRChat Chatbox` に送る
- VRChat で聞こえる音声を逆翻訳して、内容を理解しやすくする

現在の主な処理パイプライン:

- マイク翻訳: `Microphone -> ASR -> Translation -> VRChat Chatbox`
- 逆翻訳: `VRChat audio -> ASR -> Translation -> Chatbox / Floating display`

## 主な機能

- ローカル音声認識とリアルタイム翻訳
- 翻訳結果を `VRChat Chatbox` に送信
- VRChat の再生音声を聞いて逆翻訳
- 手動テキスト翻訳パネルを内蔵
- 複数の chatbox 出力形式に対応
- 多言語 UI
- ASR 辞書、自声抑制、ノイズ除去、VAD、認識パラメータ調整
- `Avatar / OSC` パラメータ同期
- 任意で使えるフローティング表示
- **ヘッドセット内での利用**：字幕板、SteamVR メニューのタブ、手首パネル、VRHandsFrame のような両手フレーム翻訳

## 動作環境

- 推奨 OS: `Windows 10 / 11`
- 逆翻訳は `Windows WASAPI Loopback` に依存します
- インストーラーに SenseVoice や TTS 音声モデルは同梱されません。各ローカルモデルは初回利用時にアプリ内のダウンローダーで準備され、既存ファイルは再利用されます。

## ソースから起動

```bash
pip install -r requirements.txt
python main.py
```

モデルキャッシュの保存先を変更したい場合:

```powershell
$env:MODELSCOPE_CACHE = "./models"
```

## 初回設定

1. アプリを起動：初回起動時に設定ファイルが作られ、利用モードのウィザード（Chatbox 翻訳 / 手入力 / 音声出力 / 相手の聞き取り / ヘッドセット字幕）が開きます
2. 既定の翻訳サービス（Microsoft Edge Web 翻訳）と音声認識（ローカル SenseVoice）は `API Key` 不要です。DeepL、Claude、OpenAI などに切り替えるときだけ `設定` でキーを入力してください
3. 必要に応じて対象言語、出力形式、マイク、逆翻訳設定を調整
4. VRChat で `OSC` を有効化
   `Action Menu -> Options -> OSC -> Enable`

## ショートカット（設定で変更できます）

- `Alt+X`：テキスト入力翻訳パネルを開く
- `Alt+C`：マイクのミュート / 解除
- `Alt+T`：スクリーンショット翻訳（デスクトップでは画面全体を翻訳）

## ヘッドセットでの使い方

Mio が自分で SteamVR を起動することはありません。SteamVR が動いていれば自動で接続し、設定で「SteamVR と一緒に起動」を選ぶこともできます。

- **字幕板**：相手の発言と自分の訳文が目の前に表示されます（大きさ・文字サイズ・背景の不透明度、ドラッグや固定が可能）。訳文の前の ● / ◆ で自分と相手を色に頼らず区別できます。
- **両手フレーム翻訳**（VRHandsFrame と同じ操作）：両手のグリップを握って看板の対角に手を構え、少し静止すると枠内の文字がその場で翻訳されます。フレーム中にトリガーを引くとその翻訳がパネルとして残ります。
- **パネル**：閉じるまで残ります。指してトリガーでボタン（原文/訳文、画像/テキスト、文字サイズ、ページ、保存、閉じる）を操作し、指したままグリップを握ると持ち上げて移動できます。
- **手首パネル**：手首を 2 回ひねる（または「手首を見る」「常に表示」）と開きます。SteamVR メニューの Mio タブと同じ操作ができ、「履歴」ページでは読んだ内容の呼び出し、パネルの整列・一括終了、両手フレームの切り替え、使い方の再表示ができます。
- **押して話す**（任意）：SteamVR のバインド画面で「押して話す」にボタンを割り当てると、押している間だけ Mio がマイクを聞きます。
- フレームの表示、読み取り開始、結果の表示、ボタン操作のたびにコントローラーが軽く振動し短い音が鳴ります（設定でオフ可）。
- 枠やパネルを操作している間、トリガーとグリップはゲームに渡しません（誤ってつかんだり撃ったりしません。設定でオフ可）。
- パネルから訳文を「コピー」したり、「チャットへ」で周りの人に送ったりできます。
- 枠内の訳文は元の文字色と背景色で描かれます。QR コードを読み取ると、パネルに「リンクを開く」（PC のブラウザで開く）が加わります。
- フレーム中はスティックで枠を拡大縮小できます。パネルを両手で持って広げたり縮めたりすると大きさが変わり、両手で持ったままトリガーを引くとページ送りや閉じる操作、片手で持ったまま同じ手のトリガーを引くとパネルを目の前に集めます。
- Quest / Rift のコントローラーはサムレストを連続タップ（既定 4 回）で両手フレームを切り替えられます。その他は SteamVR のバインド画面で「両手フレームのオン / オフ」「パネルを目の前に集める」「パネルをすべて閉じる」にボタンを割り当ててください。
- 効果音は自分の WAV ファイルに置き換えられます（設定にフォルダーを開くボタンがあります）。
- 設定で利き目を選べます（囲んだ場所と読み取りがずれるときはまずここを確認）。ジェスチャーの感度、トリガー／グリップの押し込み量、枠が出るまでの時間も調整でき、ポーズが認識されにくい場合は「クイックモード」（両手でトリガーとグリップを押すと枠が出る）が使えます。

## OSC 操作パラメータ（設定で「Avatar 操作を許可」をオン）

| パラメータ | 型 | 動作 |
| --- | --- | --- |
| `MioToggleMic` | Bool | マイクのオン / オフ（オフはミュート、相手の聞き取りは続く） |
| `MioToggleListen` | Bool | 相手の聞き取り オン / オフ |
| `MioToggleTts` | Bool | 音声出力 オン / オフ |
| `MioToggleOverlay` | Bool | デスクトップのフローティング字幕 オン / オフ |
| `MioToggleVrOverlay` | Bool | ヘッドセットの字幕板 オン / オフ |
| `MioFrameGesture` | Bool | 両手フレーム オン / オフ |
| `MioScreenshot` | Bool | 押すたびにスクリーンショット翻訳を 1 回 |
| `MioTargetLanguage` | Int | 翻訳先の言語を切り替え（1 から始まる番号、0 は変更なし） |

「Avatar 同期を有効化」をオンにすると、`MioTranslating`、`MioSpeaking`、`MioMuted`、`MioError`、`MioTargetLanguage`、`MioOverlayActive`、`MioFraming`（フレーム中）、`MioPanelHeld`（パネルを持っている）もアバターへ書き戻します。

## プライバシー

- このプロジェクトはユーザーデータを収集しません
- チャット履歴を保存しません
- 既定のログには、認識テキスト、翻訳テキスト、chatbox の内容を記録しません
- chatbox に送るテキストは送信後に保持しません
- Windows 版では、保存された API Key をシステムの DPAPI で保護します
- 自動 UI 言語判定はローカルのシステム言語のみを読み取り、IP 位置情報は既定で使用しません
- クラウド翻訳を有効にした場合のみ、現在のテキストがあなた自身の設定した API サービスへ送信されます

## 補足

- VRChat の標準 OSC では他プレイヤーの生チャット本文は取得できません
- 逆翻訳はローカル再生デバイスのループバック収録に依存するため、PC 側の音声経路の影響を受けます
- VRChat Chatbox には送信頻度と 1 件あたりの文字数制限があります
