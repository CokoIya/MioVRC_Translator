# Mio RealTime Translator v1.3.8.9

## Changes

- Added Qwen Japan workspace-endpoint support for translation, Qwen3-ASR, and Qwen TTS. Use the URL and model enabled for the selected Japan workspace.
- Fixed secure downloads from legitimate Qwen regional audio hosts and enabled native system-certificate trust for provider connections.
- Made Local AI API keys optional and improved compatible localhost and private-LAN HTTP endpoints with direct, low-latency connections.

## Upgrade

Users on v1.3.8.6 or later can update through Mio's in-app updater. Users on v1.3.8.5 or earlier must manually install this version once.
