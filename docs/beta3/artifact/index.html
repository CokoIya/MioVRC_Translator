Mio RealTime Translator · v1.4.2_beta3 · 测试版

新操作手册

这一版把头显里的“看字翻译”换成了和 VRHandsFrame 一样的玩法：两只手在面前比一个框，框住的字就地翻译，翻译还能留成面板拿在手里。聊天框、麦克风和设置也修了不少问题。这份手册只讲 beta3 新增和改变的操作。

这版改了什么

VR双手取景翻译两手比框，保持不动就把框里的字翻译好，直接显示在原文的位置。
VR翻译面板翻译可以留成面板挂在原处，一直保留到你关掉；能拿起来移动、缩放、复制、发聊天框。
VR翻译记录手腕面板里能找回这次读过的所有内容，收藏的不会被挤掉。
VR不再误操作游戏取景、指着面板时，扳机和握把不会同时触发游戏里的抓取或开枪。
VR振动和提示音手势认出、开始识别、出结果、点按钮都有振动和短提示音，可以换成自己的声音。
聊天框长句分页发送长的译文不再被截断，会分成最多 4 页依次发出；翻译时头上显示“正在输入”。
麦克风静音更可靠说完马上静音，刚说的那句也会正常翻译；静音时状态栏会写明“麦克风已静音”。
电脑端保存设置不打断改主题、快捷键或头显设置时，不会再重启监听、打断正在说的话。

更新后先做的事

直接覆盖安装即可，原来的设置会保留。进 VR 之前，建议按顺序检查下面几项：

  1. 打开截图翻译和双手取景。在电脑上打开 设置 → 听别人说话，往下找到 截图翻译 一节，勾选 启用截图翻译。双手取景翻译 默认已经勾上。在头显里也能开：手腕面板 → 翻译记录 页 → 双手取景。

  2. 确认主视眼。现在按主视眼的画面计算框住的范围，默认是右眼。如果你是左眼主视，请在 主视眼（读取哪只眼的画面） 里改成左眼。选错了，读到的字会和你框住的地方偏开一截。

    判断方法：两眼睁开，用手指对准远处的一个点，然后轮流闭上一只眼。闭上后指尖仍然对准那个点的那只眼，就是主视眼。

  3. 如果你改过 Mio 的手柄绑定，先改回默认。这版新增了好几个手柄动作。SteamVR 会一直沿用你保存过的旧绑定，新动作不会出现，“不误操作游戏”也会失效。打开 SteamVR 设置 → 控制器 → 管理控制器绑定，选 Mio，然后换回默认绑定。没改过绑定的玩家不用管这一步。

  4. 第一次戴上头显时看一眼说明。头显第一次戴上时，面前会出现一块操作说明面板。看完点 关闭，之后可以在手腕面板 → 翻译记录 → 操作说明 里再打开。

双手取景翻译

用来读告示、菜单、世界里的说明文字等。整个过程不用按任何按钮：比框、停住、看译文。

基本操作

  1. 两手都按住握把（侧面那颗键），放在要读的文字的对角，比如左手在左上、右手在右下。两手要在身前、手臂自然伸出的距离，两手相距十几厘米以上。

  2. 约 0.3 秒后框就会出现，同时手柄轻振、有“叮”的一声。框会跟着手移动，这时可以调整框的大小和位置。

  3. 保持不动约 0.6 秒，框底部的进度条走满后开始识别。几秒内译文会出现在框里、原文的位置上，默认按原文的字色和底色来画。

  4. 想把这次翻译留下来，就在框还在的时候扣一下扳机（任意一只手），它会变成一块面板挂在原处。只是看一眼的话，松开握把框就消失了。

框的颜色

白色手势已认出，正在对准。保持不动时，底部进度条会走。
青色正在识别和翻译，请保持框的位置。
绿色译文已显示在框里。手一移开，译文就会清掉，重新对准。

更多用法

  • 框大了或小了：取景时推摇杆，向上放大、向下缩小（0.4 到 3 倍）。取景期间推摇杆不会让角色走动。
  • 框里没找到字：框里会提示“画面上没有找到可以识别的文字”，并且不会反复识别同一个地方。稍微挪一下框，就会重新识别。
  • 识别到一半就松手了：结果会以翻译卡片的形式短暂显示，同时存进翻译记录，之后可以从手腕面板找回。
  • 读到二维码：框里会提示二维码的内容。扣扳机把它留成面板，面板上会多一个 打开链接 按钮，链接在电脑的浏览器里打开。只会打开 http / https 网址，其他内容一律不会打开。
  • 姿势总是认不出来：在设置里把 手势灵敏度 调高，或者打开 快速模式。开了快速模式后，双手同时按住扳机和握把就会直接出现框，不用摆对角，框太小时会自动放大。出框后松开扳机、只按住握把就能移动，再扣一下扳机就把结果留成面板。
  • 不想自动翻译：关闭 取景后保持不动自动翻译，之后要在取景时扣扳机才会翻译。
  • 拿着东西举到面前时误出框：把灵敏度调低；或者在手腕面板 → 翻译记录 页点 双手取景 临时关掉。

其他开始翻译的方式（仍然可用）

  • 按住扳机和握把，再按 B（右手）或 Y（左手），会打开取景框：激光点一下，就翻译绿框里的内容；拖动可以自己框选范围；再按一次 B / Y 翻译整个画面。
  • 把手柄举到耳边，短按一下扳机，也会打开取景框。
  • 手腕面板或 SteamVR 菜单里的 翻译整个画面。
  • 电脑上按 Alt+T（桌面截图翻译快捷键）。

翻译面板

留下来的翻译会变成一块面板，挂在原文的位置，一直保留到你关闭它，不会自己消失。同时最多挂 4 块，再开新的时，最早的那块会被收起（它仍然在翻译记录里）。

用 B/Y 或贴耳手势翻译的结果现在也默认是面板。如果你更喜欢以前那种看一眼就消失的卡片，把 结果显示方式 改成 翻译卡片。

面板上的按钮

用另一只手柄指着面板（会出现激光和光标），扣扳机点按钮。手柄的按键绑定暂时没生效时，把光标停在按钮上约 1 秒也算点击，光标外会有一圈进度。

设置里开着 激光停在按钮上时显示说明 时，指着某个按钮，面板标题栏会显示这个按钮是做什么的。

移动、缩放和双手操作

  • 移动：指着面板按住握把，面板会跟着手走，而且始终朝向你。松开握把就放下了。
  • 缩放：一只手拿着面板时，另一只手也握住它，双手拉开就放大，合拢就缩小。
  • 双手拿着时扣扳机：默认左手扳机翻上一页，右手扳机翻下一页，已经是最后一页时右手扳机直接关闭面板。左右手分别做什么可以在设置里改。
  • 单手拿着时扣同一只手的扳机：把所有面板收拢到面前，排成一排。

手腕面板和 SteamVR 菜单

手腕面板默认在左手，快速扭两下手腕出现，再扭两下收起。用另一只手柄的激光点按钮。设置里的 手腕面板出现方式 还可以选 抬起手腕看向手背（像看手表） 或 一直显示。SteamVR 菜单里的 Mio 标签页和手腕面板是同一套按钮。

主页面的 截图翻译 一栏新增了两个按钮：双手取景（开关双手取景）和 翻译记录（n）。点翻译记录进入第二页：

  • 收拢面板：把所有打开的面板排到你面前。
  • 关闭全部面板：一次收起所有面板。
  • 操作说明：重新打开首次使用时的说明面板。
  • 记录列表：本次运行中读过的内容，最新的在上，收藏的排在最前。点一条就在面前打开成面板，点右边的 ☆ 收藏。记录只在这次运行期间保留，关闭 Mio 后就清空，不会保存到硬盘。
  • ◀ 返回：回到主页面。

按键、声音与说话

取景和操作面板时不会误触游戏

摆取景手势时，两只手的握把和扳机不会传给 VRChat，所以不会抓起东西或开枪。激光指着面板、拿着面板、点手腕面板时，只接管正在用的那只手。其他时候游戏照常收到所有按键。这项功能需要 SteamVR 已经启用 Mio 的按键绑定，可以在设置里关闭（取景和操作面板时不把扳机、握把交给游戏）。

扳机和握把的手感

  • 扳机按到多深算按下 默认 50%，握把握到多紧算按下 默认 40%。Index 手柄如果要用力捏握把才能保持取景框，把握把的值调低；误触多就调高。
  • 读不出按压力度的手柄（比如 Vive 手柄的握把）仍然按“按下 / 松开”判断，滑块对它们不起作用。
  • 和游戏按键冲突时，可以勾 扳机和握把对调。

快捷动作

  • Quest / Rift 手柄：连续轻点拇指托（摇杆旁边放拇指的平面）4 下，开关双手取景。次数和要执行的动作都能在设置里改，也可以设成收拢面板或关闭全部面板。
  • 其他手柄：在 SteamVR 绑定页里给 开关双手取景、把面板收拢到面前、关闭全部面板 各指定一个按键。默认都不绑定，因为常用的按键都被游戏占了。

按住说话

勾选 按住手柄键说话（松开即静音），然后点 打开 SteamVR 按键绑定，给“按住说话”选一个按键。之后 Mio 只在你按住这个键时收音，松开就静音。按住和松开时各有一声短提示。开启后，VRChat 里的麦克风静音状态不会再同步到 Mio，以免两边互相打架。

振动和提示音

取景框出现、开始识别、出结果、留成面板、点按钮、切换开关时，手柄都会振动并发出短提示音。振动、提示音、音量都能分别关掉或调节。

想换成自己的声音：点 打开自定义提示音文件夹，把同名的 WAV 文件放进去就行。可以替换的文件：

文件名什么时候响
ready.wav取景框出现
done.wav翻译结果出来
shutter.wav留成面板
error.wav没读到字、识别或翻译失败
click.wav点按钮
toggle.wav手腕面板出现或收起，切换开关
talk_on.wav / talk_off.wav按下 / 松开“按住说话”

只支持 WAV 格式，自定义声音不受音量滑块控制。

头显字幕板

  • 新增 字幕字号，可以单独放大或缩小字幕板上的字。
  • 译文前面会加上形状标记：● 表示你自己说的，◆ 表示别人说的。不用靠颜色也能分清，色弱玩家也不会看混。不需要的话可以关闭 译文前加形状标记。

聊天框与麦克风

  • 长句分页：超出聊天框长度的内容不再被截断，会在句号、逗号或空格处断开，分成最多 4 页，每页间隔约 2.5 秒发出。
  • “正在输入”气泡：你的话在识别和翻译的时候，头上会显示正在输入，发出后自动消失。
  • 停止时清空聊天框：停止监听时，如果聊天框里是 Mio 发的内容，会把它清掉。你自己用 VRChat 键盘打的字不会被清掉。
  • 别人的话默认不发到公共聊天框：新安装时 别人的话→Chatbox 默认关闭，避免把别人说的话用你的名字公开发出去。老玩家保持原来的设置不变，可以在手腕面板上随时切换。
  • 说完马上静音，最后一句也会翻译：以前刚说完就静音，这句话会被吞掉，现在会正常翻译并发出。静音期间说的话仍然不会被收录。
  • 静音状态看得清：静音时，主界面和手腕面板会显示“正在听（麦克风已静音）”，不会再显示成正在听。
  • 安静的房间里麦克风不再反复重启。

电脑端的变化

  • 保存设置不再打断：只有改了识别、翻译服务、音频这些监听要用的设置才会重启监听。改主题、快捷键、头显设置时，正在说的话不受影响。
  • 自动断句校准更方便：不用先开始监听也能校准，校准时说的测试语音也不会被翻译发出去。
  • Claude 翻译恢复可用，在设置里选择并填写 API Key 就能用。
  • 免费翻译互相备用：用微软 Edge、Google、MyMemory 这类免账号的网页翻译时，其中一个连不上，会自动改用另外两个。连续失败的那个会先歇两分钟，不再每句都卡着等它超时。
  • 本地 Whisper 识别已移除。原来选了 Whisper 的，会自动换成本地 SenseVoice。
  • 使用模式向导：选择 VR 头显字幕 时，会同时打开头显字幕板、截图翻译和双手取景。
  • 听别人说话的翻译目标：新安装时，默认翻译成界面语言，而不是一律中文。

常见问题

摆了手势但框不出来

按顺序检查：

  • 启用截图翻译 和 双手取景翻译 是否都勾上了。
  • 两只手是不是都按住了握把，并且放在对角（不是左右并排，也不是上下叠着）。
  • 手离脸不要太近，也不要伸到最远，手臂自然伸出就好。
  • SteamVR 是否启用了 Mio 的手柄绑定。设置页里会显示绑定状态；如果改过绑定，请换回默认。

还是不行的话，把 手势灵敏度 调高，或者打开 快速模式。

框住的地方和读到的字对不上，总偏一点

多半是主视眼选错了。把 主视眼 换到另一只眼再试。

取景时角色还是抓起了东西 / 开了枪

先确认 取景和操作面板时不把扳机、握把交给游戏 是勾上的，并且用的是 Mio 的默认绑定。改过绑定的，新动作不会生效，这项功能也会一起失效。PICO 等手柄如果一直显示“绑定未生效”，这项功能用不了，请把情况反馈给作者。

按钮点不动

把激光光标停在按钮上约 1 秒，也会点击（光标外圈会走一圈进度）。这是给扳机绑定还没生效的情况准备的。

译文的颜色看不清

渐变底色、带花纹的告示上，颜色可能推测不准。可以关闭 译文使用原文的颜色，改回统一的白字黑底。

面板太多、挡住视线

在手腕面板 → 翻译记录 页点 关闭全部面板，或者点 收拢面板 把它们排到面前再一块块关。关掉的面板在记录里都还在。

截图时会不会把 Mio 自己的面板也截进去

不会。每次识别前，字幕板、取景框、面板、手腕面板和激光都会先暂时隐藏，截完再恢复。

Mio 会自己启动 SteamVR 吗

不会。SteamVR 运行时 Mio 会自动接上。想让 SteamVR 启动时顺便打开 Mio，勾选 随 SteamVR 启动。
