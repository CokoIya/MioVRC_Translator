# Mio RealTime Translator v1.5.0 — Mio VR手势

本版重点是 SteamVR 适配：不用摘下头显，即可取景翻译、查看字幕和回顾聊天记录。桌面翻译、ASR、TTS 仍使用 Mio 原有服务与配置。

## VR 功能

- **双手取景**：双手按住握持键（手柄侧面的按键）框选区域；左扳机切换拍照、翻译和二维码模式，右扳机执行截取／书签操作。完整操作见应用内教学。
- **截图翻译**：单独选择原文和译文语言，不与说话翻译／反向翻译共用语言设置；预览固定在截取时的位置，可转头阅读。
- **结果面板**：查看图片、原文和译文，翻页、调字号；靠近面板按握持键搬移，双手握持缩放。
- **手腕书签与双向记录**：按住左扳机并抬腕打开，松开扳机后保持显示；可查看自己和对方的转译记录。记录与书签仅保留于本次会话，不是永久存档。
- **二维码链接**：扫描后显示链接，仅在明确点击“打开链接”后访问 HTTP(S) 地址。
- **实时字幕**：默认固定朝向，随实际位置平移但不随转头旋转；“移到眼前”可重新定位，也可选用跟随头部模式。
- **交互修整**：改善教学指针焦点、进度提示清理和手腕误触；译文直接发送到 VRChat Chatbox，不显示“正在输入”。

## 使用条件与数据

- Windows x64；VR 功能需要正在运行的 SteamVR、正常追踪的头显及兼容控制器。
- 如需拦截游戏输入，请在 Mio VR 设置中主动启用 SteamVR 输入覆盖，并在游戏中验证绑定。
- 在线翻译、ASR、TTS 仍按所选服务的规则发送内容；本地语音模型按需下载，不捆绑进安装包。
- 图片只在点击“保存图片”后写入本地；不要把会话书签当作永久备份。
- 不含 VRHandsFrame 的 GIF 录制、云分享或 PIN 服务，也不要求安装 VRHandsFrame。

## 公开源码与完整安装包

本 Release 的官方安装包包含 VR 功能。v1.5.0 标签及 GitHub 自动生成的 Source code 压缩包对应可独立运行的非 VR 桌面版，保留 ASR、翻译、TTS、Chatbox、反向翻译及桌面字幕；VR 实现另行维护，不包含在当前公开源码树中。既有公开历史不改写。

## 安装与升级

使用 `MioTranslator-Setup-v1.5.0.exe` 安装或升级；建议先退出正在运行的 Mio。v1.3.8.5 及更早版本请手动安装。

官方完整安装包保持已验证的 v1.5.0 构建，不因公开源码拆分而改动功能逻辑。旧版 dist 产物保留；安装包及签名验证以最终构建记录为准。
